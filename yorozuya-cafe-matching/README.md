# 稲沢よろずやCafe マッチング診断 共有用

このフォルダは、スマホで開ける診断アプリを共有するための公開用フォルダです。

## 中身

```text
index.html
```

HTML、CSS、JavaScriptだけで動きます。
外部サーバー、データベース、AI APIは使っていません。

## 共有方法

### おすすめ: GitHub Pages / Vercel / Netlify に置く

`index.html` を静的サイトとして公開すると、URLをQRコード化して参加者に配れます。

公開後のURL例:

```text
https://example.com/
```

### 手元で確認する

`index.html` をダブルクリックするとブラウザで開けます。
